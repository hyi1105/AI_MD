## 背景

公司不想為 Power Apps／Automate 進階加價 → 紙本風純文字網站＋可設定欄位＋簽名流水線＋類 LINE 對話＋依身分顯示隱私欄。

1. 介面＝紙本風網頁（可設計預覽）  
2. 表單引擎＝JSON schema  
3. 共用＝SharePoint 清單  
4. 隱私＝個人空間＋只存 user ID；別人畫面**無此格**  
5. 通知＝可選 Teams；對話在網站對話室  
6. 身分＝Entra ID  

本階段不做：付費進階連接器、一開始接內網 SQL。

## 產品區塊

| 區塊 | 行為 |
|------|------|
| 紙本表單 | 純文字；欄可設；內部名＋顯示名 |
| 欄位 | 文字／數字／下拉／是非／人員；必填／條件／顯示／唯讀 |
| 按鈕 | 送出、核准、駁回（可退回、通知請簽） |
| 簽名流水線 | 換代理／換簽／退回／通知／看資料 |
| 對話室 | LINE 格；格可限定欄位 |
| 分層 | 需簽核可見 vs 僅自己可見 |

## 架構 12345（3＝主錨）

```
1 登入 ID → 2 表單引擎＋紙本 → 3 雙層資料家（SharePoint｜個人空間）
→ 4 簽名流水線 → 5 對話室＋可選 Teams
```
