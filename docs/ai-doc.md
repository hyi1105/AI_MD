# AI Doc — 像 Cursor 一樣，用 AI 改每一份檔並顯示修改處

> 這是主題下的一類 **AI 資料收集／輸出工具**（不是子專案）。  
> **舊稱**：SmartDoc／文稿（manuscript）。  
> 主題：[`00-theme.md`](./00-theme.md) · 構想：[`01-idea.md`](./01-idea.md) · 查核：[`03-checklist.md`](./03-checklist.md)

---

## 目標（一句話）

讓 **AI 能像 Cursor 一樣重新編輯每一份檔案**；AI 產出修訂後，**清楚顯示修改的部分**（視覺化 Diff：紅刪／綠增），使用者可接受或拒絕後寫回同一份檔。

---

## 1. 核心能力

### 1.1 AI 改檔（像 Cursor）

* 使用者用自然語言下指令（可 Mention 章節）  
* AI 針對**目前這一份檔**產生修訂建議（不是另開一本無關的新檔當主流程）  
* 現況：示範用規則引擎；真 LLM 見 `01-idea`

### 1.2 顯示修改處（編譯／產出後）

* AI「編譯」出建議後，以 **視覺化 Diff** 標出變更段落  
* 支援單處／全部 Accept／Reject，結果寫回同一份 Markdown  
* 這是產品主路徑，優先於 P2P／分紅等輔助能力

### 1.3 同一份檔持續編修

* 底層格式：Markdown  
* 可切換預覽模式（合約／流程圖／報告等），底層仍是同一份內容  

### 1.4 輔助（非主定位）

* 內容指紋、P2P、額度 UI：若保留，須標示示範／次要，避免蓋過「AI 改檔 + 顯示 Diff」
