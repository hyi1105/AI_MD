# AI 工具搜尋 — Web 原型

桌面測試版整合至此目錄，可直接在瀏覽器開啟。

## 本地預覽

雙擊 `index.html`，或在專案根目錄執行：

```powershell
start web\index.html
```

## 檔案

| 檔案 | 說明 |
|------|------|
| `index.html` | 主頁 |
| `style.css` | 樣式 |
| `script.js` | 搜尋、排序、渲染邏輯 |
| `data.js` | 24 個 AI 工具資料 |

## 後續

- 工具資料可逐步遷移到 `content/tools/*.md`
- 正式版見 `modules/ai-tools-directory.md` 規格
