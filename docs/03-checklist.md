## 5. 本機開發（給實作者）

```powershell
cd web
.\start-local.ps1
# 或：python -m http.server 8080
```

```bash
cd smartdoc-ai
npm install
npm run build   # → web/smartdoc/
```

- [ ] 本機 HTTP 下詳情 MD 可正常 fetch（勿只靠 `file://`）
