# 00 — SEED Platform（產品是什麼）

> 更新：2026-07-19  
> 一句話：**SEED 是一本可累積、可分享、可商業化的「知識書」；本站是長期關注某個產品或 KOL 知識的地方。現有功能都只是採集與輸出工具。**

相關文件：[`01-idea.md`](./01-idea.md)（待做與前因後果）· [`02-idea-done.md`](./02-idea-done.md)（已完成／已取消）· [`03-checklist.md`](./03-checklist.md)（使用者操作驗收）· [`prompts/AGENT-MASTER.md`](../prompts/AGENT-MASTER.md)（AI 規則）

## 1. 什麼是 SEED

| 名稱 | 意思 |
|------|------|
| **SEED** | 一個人（或一個產品／KOL）長期累積下來的專業知識單位，像一本持續更新的書 |
| **讀者／關注者** | 長期追蹤某本 SEED，取得結構化知識 |
| **編排者** | 可整理、策展、重新編排他人開放的 SEED（授權範圍內） |
| **商業行為** | 訂閱、單次解鎖、分成、授權轉載等（後續） |

SEED 的本質是 **輸出結果（知識資產）**，不是某個單一編輯器功能。

> 產品語言的 **SEED（知識書）** ≠ SmartDoc 實作裡的內容指紋 `sd_…`（edition fingerprint）。

---

## 2. 網站要成為什麼

**長期關注導向的知識站**，服務兩類主體：

1. **產品（Product）** — 官方或社群為某產品累積的使用知識、決策紀錄、最佳實務  
2. **KOL／專家** — 個人專業知識的長期出版與更新

訪客來這裡不是「用一次工具就走」，而是 **關注 → 累積 → 回訪 → 分享／購買**。

## 3. 功能在架構裡的位置

現有模組都是 **採集／加工工具（Collectors）**，目的是幫助產出 SEED：

```text
                    ┌─────────────────────────┐
                    │   SEED Platform（本站）   │
                    │  長期關注 · 知識書 · 商業  │
                    └───────────┬─────────────┘
                                │ 產出 / 累積
              ┌─────────────────┼─────────────────┐
              ▼                 ▼                 ▼
        AI 查詢工具         SmartDoc 編輯      （未來）SEED 書架
     發現、對照、蒐集      編修、Diff、P2P      關注、編排、分享
              │                 │                 │
              └────────────┬────┘─────────────────┘
                           ▼
                    SEED（Markdown 知識書）
```

| 工具 | 角色 | 對 SEED 的貢獻 |
|------|------|----------------|
| **AI 查詢工具** | 發現與對照外部 AI／資訊 | 幫作者蒐集素材與對標 |
| **SmartDoc** | 編修、視覺化 Diff、離線協作 | 把素材寫成可版本化的 `.md` 書 |
| **技術內容指紋**（SmartDoc 內） | 內容定址 ID | 某一版內容的指紋；≠ 產品概念本身 |

> 勿把「編輯器」或「P2P」當成產品本體；它們是寫書／傳書的工具。

---

## 4. 商業與分享（方向）

- 作者累積 SEED → 開放部分章節／付費解鎖  
- 他人可在授權下 **編排、轉述、二次策展**  
- 平台可抽成或提供付費關注（細節待負責人拍板，見 `01-idea.md`）  
- 去中心化傳輸／分紅（既有 P2P 草案）服務「傳書與節點貢獻」，服從 SEED 主線
