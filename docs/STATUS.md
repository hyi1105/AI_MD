## 1. 這個系統在做什麼？

**一句話**：網站要成為「長期關注某個產品或 KOL 知識」的地方；大家把專業累積成 **SEED（知識書）**，別人可關注、編排、分享，以後可商業化。

**現在實際長怎樣**：

```text
SEED 平台（品牌／定位已上線）
├── 採集工具 A：AI 查詢目錄     → 找素材、對標工具（較完整）
├── 採集工具 B：SmartDoc 編修   → 寫書、Diff、本機示範 P2P（半成品）
└── SEED 書架／關注／付費分享   → 尚未打造（真正的平台本體）
```

| 區塊 | 路徑 | 現況 |
|------|------|------|
| 平台入口＋品牌 | `web/index.html` | ✅ 已上線 SEED 說明＋工具切換 |
| AI 查詢目錄 | `web/catalog.json` 等 | ✅ 約 300 筆搜尋／追蹤／詳情 |
| SmartDoc | `smartdoc-ai/` → `web/smartdoc/` | ✅ 可玩的編修 demo |
| 部署 | GitHub Pages | ✅ push `main` 自動部署 |

## 2. 哪裡是真的？哪裡是假裝的？

| 能力 | 狀態 | 說明 |
|------|------|------|
| 工具目錄搜尋／追蹤 | **真的** | 瀏覽器端搜尋 `catalog.json` |
| 多模式渲染＋紅綠 Diff | **真的** | SmartDoc 主畫面可用 |
| Markdown 本機儲存 | **真的** | `localStorage` |
| 內容指紋 `sd_…` | **真的** | SHA-256（技術 id，≠ 知識書 SEED） |
| AI 對話改稿 | **模擬** | 規則引擎，沒打真實 LLM API |
| LAN／藍牙／libp2p | **模擬** | 只有按鈕與延遲，沒有真連線 |
| CRDT 多人合併 | **示範** | 自寫段落合併，不是 Yjs／Automerge |
| 訂閱／NT$ 付費 | **模擬** | 改本機額度，沒有金流 |
| Word `.docx` 匯出 | **假的** | 下載的是 Markdown |
| SEED 書架／關注 KOL | **未做** | 平台核心尚缺 |
| 登入／跨裝置 | **未做** | 資料只在你瀏覽器 |

## 3. 已知問題（請優先知道）

| 嚴重度 | 問題 | 建議 |
|--------|------|------|
| 高 | `web/tools/*.md` 約 300 篇**標題亂碼**（編碼問題）；目錄中文正常 | 修產生腳本編碼，或詳情改走 catalog 欄位 |
| 高 | 目錄卡片用 `innerHTML` **未跳脫**，惡意資料可能 XSS | 渲染前 escape |
| 中 | SmartDoc AI **對外寫真實模型名**，實際沒呼叫 | 文案改成「示範引擎」或接真 API |
| 中 | Seed 索引每改一版存一份，**localStorage 可能膨脹** | 清舊版或只留最近 N 版 |
| 中 | `modules/ai-tools-directory.md` 的 F-10 曾標 `deferred`，與線上 Pages、`01-requirements` 的 `done` 打架 | 規格已改對齊；若再出現以本檔＋線上為準 |
| 低 | Repo 名仍叫 `AI_MD`，產品叫 SEED | 之後可改名或只當歷史網址 |
| 低 | `docs/03-implementation.md` 等舊文曾寫列表在 `data.js` | 實際列表為 `catalog.json`；改 HOW 文件時一併校正 |

## 6. 需要你（負責人）拍板／留意的事

### 產品決策（只有你能定）

1. 下一季重心：**先做 SEED 書架**，還是先把 SmartDoc AI 接真模型？  
2. 商業要不要做？做訂閱還是打賞／單次解鎖？  
3. P2P／分紅是正式路線，還是長期保持「示範」？  
4. GitHub 專案要不要改名／自訂網域成 SEED？  

### 接真服務前必備

- [ ] LLM：選供應商、帳單、金鑰怎麼放（純 GitHub Pages **不能**安全藏 server key → 要後端或使用者自備 key）  
- [ ] 金流：金流商、退款、發票／稅務  
- [ ] 隱私權／使用者條款（一有帳號或付費就需要）  
- [ ] 目錄內容來源與正確性責任邊界  

### 每次對話怎麼跟我配合

1. 你說想法或畫面問題（不必講程式）  
2. 我**預設只改 Markdown（繁體中文）**——規格、本檔、standup、prompts  
3. 你明確說「**改程式**」→ 我才改 `web/`／`smartdoc-ai/` 等  
4. 你明確說「**發布**」→ 我才 commit／push／上線  
5. 每次都回寫**本檔**對應區塊（完成／未做／問題）
