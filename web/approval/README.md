# Approval｜LINE 對話＋格式卡

- **一般聊天**：像打 LINE（訊息氣泡）
- **格式卡**：另一個東西——像手上拿的文件（必填欄）
- **送出申請**＝`submit`；**核准**＝`approve`
- **駁回／退回**：對話裡的系統訊息＋按鈕

Schema：[`../schema/form-schema.example.json`](../schema/form-schema.example.json)
