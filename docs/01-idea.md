# 01 — 構想與待辦（Idea）

> 用途：把每次對話／會議的輸入，整理成**還要做的工作項目**，並留下前因後果。  
> 以後問「為什麼會有這個功能？」→ 先查本檔，再對照 [`02-idea-done.md`](./02-idea-done.md)。  
> 更新：2026-07-19

### 怎麼寫一筆（模板）

```markdown
### IDEA-xxx — 短標題
- 狀態：open｜waiting-owner｜blocked
- 來源：YYYY-MM-DD 對話／會議
- 為什麼：…
- 要做什麼：…
- 驗收線索：見 03-checklist 哪一節（若有）
```

新項目加在**對應分類最上方**；完成或取消後**整段剪到** `02-idea-done.md`。
