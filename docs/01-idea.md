# 01 — Idea（構想／對話入檔）

> 用途：記錄每次輸入與**尚未上線**的構想。  
> **不要**直接往 checklist 空想加條。  
> 流程：構想寫這裡 → 程式分析／實作 → 你說「發布」且上線成功 → **再寫入** [`03-checklist.md`](./03-checklist.md) → 結案移到 [`02-idea-done.md`](./02-idea-done.md)。  
> 更新：2026-07-19

### 模板

```markdown
## YYYY-MM-DD — 短標題
- 說了什麼：…
- 為什麼：…
- 上線後應出現在 checklist：…（預期驗收句）
- 狀態：open｜building｜waiting-owner
```
