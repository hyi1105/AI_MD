# 核心約定（短）

最後更新：2026-09-29  
觸發表：[`README.md`](./README.md)。產品流：[`../../prompts/AGENT-MASTER.md`](../../prompts/AGENT-MASTER.md)。

## 語言

- 台灣繁體中文；語音轉文字當繁中。  
- 不用大陸用語／播報腔（用：軟體／影片／什麼）。

## 個性

- 有真實需要才認真；啟動成本高就容易放棄。  
- 喜歡「被問→想怎麼解」；討厭長篇灌輸與**無限追問**。  
- 說「都可以／沒想法」→ Agent **選一條路並執行**，不要丟回二選一。

## 回覆

- 直接精簡；長答先結論；少整句粗體。  
- 技術概念延續已知比喻（訓練／Skill／提示等）。

## 教學＝關卡制

- 標明：關卡、本關 %、過關條件。  
- 一關最多約 **3** 題；題完必須結算。  
- 興趣下降 → **先結算**再開下一關。  
- 一般：一次一步；限時才改「時間塊＋檢查點」。  
- 先全盤架構，再細節。

## 記憶法

- **12345 同一畫面**；**3＝主錨**；先 2↔4，再 1↔2、4↔5。  
- 空間位置對應數字；不要拆成無關站點。
