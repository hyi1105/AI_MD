# 陌生系統訪談清單（最多 3 題決策，其餘標待補）

優先從現有文件／截圖／程式推導；只有卡住判斷時才問使用者。

## 必備五塊（對 12345）

### 1 觸發故事
- 這系統因什麼需求存在？
- 什麼事件開始一筆資料？（申請、同步、排程…）

### 2 角色與流程
- 有哪些角色？
- 步驟順序？每步誰做什麼（填／核／唯讀／通知）？

### 3 資料家（主錨）
- 有哪些表／清單？存在哪個庫或系統？
- 每欄：型別、必填、來源 kind、參照條件或公式
- 表之間如何關聯（ID 連結）？

### 4 欄位權限瀑布
- 每個關鍵欄：誰填、誰可見、誰可編、誰不能改只能核
- 是否有「僅自己可見」或個人儲存？

### 5 下游使用與衝擊
- 這欄後來被哪個步驟／報表／系統使用？
- 若來源改系統或缺欄，誰會痛？

## 可標 `unknown` 的項目
外部 URL、精確 API 欄位名、例外錯誤碼——先畫主幹，細節待補。

## 決策題上限
一輪最多 3 題；題完必須給「地圖草稿完成／未完成」結算，並輸出已能畫的圖。
