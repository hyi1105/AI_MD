# 教學節奏與工具

最後更新：2026-09-29  
觸發：在教操作、開關卡、切主題。

## 節奏

- 一般：**一次一步／一關**；回報完成再下一步。
- 限時衝刺：時間塊＋檢查點；塊初講清目標與產出。
- 先地圖與優先順序，再深讀；避免過早鎖死單一章。

## 工具

| 誰 | 做什麼 |
|----|--------|
| Cursor／本 Agent | 地圖、關卡、決策題、對工作、跑 code／排錯 |
| NotebookLM | 只依上傳來源；語音提示見 `NotebookLM.md` |
| 一般 Gemini／ChatGPT | 廣問可以；與指定教材一致時以 NotebookLM 為準 |

## 開新主題

1. 切關卡表（過關條件＋預估 %）  
2. 先給地圖；問要開第幾關，或只要地圖
