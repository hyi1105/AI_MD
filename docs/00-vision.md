# 00 — 專案願景（摘要）

> 完整北極星已移至 **[00-seed-platform.md](./00-seed-platform.md)**（2026-07-19）。

## 一句話

**SEED Platform** — 長期關注產品或 KOL 知識；把專業累積成可分享的 **SEED（知識書）**。  
AI 查詢與 SmartDoc 只是採集／輸出工具。

## 本專案做

- SEED 知識書定位與平台入口
- 採集工具：AI 工具目錄搜尋、SmartDoc 編修
- GitHub Pages 公開站

## 後續（商業／書架）

- SEED 書架、關注、編排、分享
- 訂閱／解鎖等商業行為
- 去中心化傳輸作為「傳書」能力（非本體）

舊版「只做 AI 工具搜尋」敘述已退役，勿再當作產品邊界。
